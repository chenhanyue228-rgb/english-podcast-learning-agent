# 外部用户招募文案

你好！我正在测试一款“英语音频学习助手”，它可以把 Podcast、RSS 或本地英语音频整理成 Notion 学习笔记，帮助你积累专业表达和自己选中的生词。

想邀请你参加一次 **45-60 分钟** 的首次使用体验。你不需要技术或编程背景，只需要：

- 一台 Mac；
- 一个可以使用的 Notion 账号；
- 可以使用 Skill 的 Codex 或 ChatGPT 环境；
- 一段不包含个人、公司或客户敏感信息的英语音频，例如公开的 Apple Podcasts 单集、Podcast RSS，或你有权使用的本地音频。

测试会从安装和第一次设置开始。过程中请按自己的理解操作并说出想法，我们观察的是产品是否清楚，不是在考核你。你不需要使用 Git，也不会被要求把密钥、密码、私人 Notion 链接或私人学习内容发给我们。输入敏感信息时会使用本地安全设置，并暂停任何可能看到敏感内容的录屏或共享。

如果你愿意参加，请回复你方便的时间，以及你是否已经有 Notion 和 Codex/ChatGPT 使用环境。谢谢！
