# 英语音频学习助手用户指南

English Audio Learning Agent（英语音频学习助手）使用 Codex（代码执行代理）
推进流程，使用本地 Python（本地程序运行环境）完成确定性处理，并把学习结果
保存到 Notion（知识管理工具）。

普通用户不需要寻找项目目录，不需要输入 `cd`，不需要手动创建虚拟环境，也不
需要手动执行主要处理命令。

## 开始前准备

需要：

- 英语音频学习助手技能。
- 完整本地项目。
- 一个可使用的 Notion 工作空间。
- 用户自己创建的 Notion 内部连接。
- Notion 内部连接的访问密钥。
- 已授权给内部连接的父页面。
- 项目内 Python 运行环境；Codex 会负责定位和准备。

不需要：

- OpenAI API 密钥。
- Codex 的 Notion 插件。
- 手动创建四个数据库或编辑 `.env`。

可选：

- Codex 的 Notion 插件，仅用于搜索、读取或辅助查看已有内容。

Notion 插件仅是可选的搜索、读取和辅助查看工具。插件授权不会传递给本地
Python，也不能代替 `NOTION_TOKEN` 或 `setup_workspace` 第一次设置流程。
数据库创建、验证和学习内容写入始终由本地 Python 通过用户自己的 Notion
内部连接完成，不存在第二条插件写入路径。不要让插件和本地设置分别创建
数据库。

## 1. 安装阶段

第一次安装时，把下面这段话发送给 Codex：

```text
请从下面的项目安装英语音频学习助手：

https://github.com/chenhanyue228-rgb/english-podcast-learning-agent

安装成功后，请直接在当前对话中带我继续第一次设置。
```

GitHub（代码托管平台）仓库地址只在安装阶段提供一次。第一次设置和日常使用
不再需要仓库地址。

技能文件夹和完整本地项目是两个层次：

- `skill/` 让 Codex 识别英语音频学习助手及其执行规则。
- 完整项目包含 `scripts/`、`src/`、依赖和验证逻辑，是本地处理与 Notion
  写入所必需的运行环境。

只安装 `skill/` 不能代替完整本地项目。Codex 会自动获取或定位完整项目，
普通用户不需要知道项目文件夹路径。

## 2. 安装完成后的交接

安装完成后，Codex 应在当前对话中显示：

```text
英语音频学习助手已经安装完成。

现在可以在当前对话中继续第一次设置。

是否现在继续？
```

用户只需要回复：

```text
继续
```

当前对话优先继续，不强制新建对话，也不要求用户记住固定指令。

备用指令是：

```text
请使用英语音频学习助手，带我完成第一次设置。
```

只有当前对话暂时没有识别到新安装的技能时，才新建一个 Codex 对话并发送
备用指令。如果新对话仍未识别，才重启 Codex 后重试。

顺序始终是：

```text
当前对话继续
↓
新建对话作为第一次备用
↓
重启 Codex 作为第二次备用
```

## 3. 创建 Notion 内部连接

官方入口：

- [Notion 开发者后台](https://www.notion.so/developers)
- [Notion 内部连接说明](https://developers.notion.com/guides/get-started/internal-connections)

操作步骤：

1. 登录 Notion。
2. 打开 Notion 开发者后台。
3. 创建新的内部连接。
4. 名称建议填写“英语音频学习助手”。
5. 选择用于学习资料的工作空间。
6. 确认连接拥有读取内容、插入内容和更新内容的能力。
7. 复制内部连接的访问密钥。

只有拥有相应权限的工作空间成员才能创建内部连接。新连接默认不能访问任何
页面。

访问密钥是私密信息：

- 不得发送到 Codex 对话。
- 不得提交到 GitHub。
- 不得出现在截图、日志或普通文档中。
- 只粘贴到后续由 Codex 打开的本地安全输入界面。

## 4. 创建 Notion 父页面

官方说明：

- [创建 Notion 页面](https://www.notion.com/help/create-your-first-page)

操作步骤：

1. 在 Notion 左侧栏创建一个新页面。
2. 页面名称建议填写“英语音频学习助手”。
3. 保持为空白页面。
4. 不要手动创建数据库。

本地程序随后会自动创建：

- Podcast Library（播客资料库）
- Expression Database（表达资料库）
- Weekly Review（每周复盘资料库，存放 Weekly Reflection 每周复盘内容）
- Vocabulary Database（词汇资料库）

## 5. 把内部连接添加到父页面

1. 打开刚创建的父页面。
2. 点击页面右上角的三个点。
3. 找到“连接”或具有相同含义的页面连接入口。
4. 点击“添加连接”。
5. 搜索并选择“英语音频学习助手”。
6. 确认该连接可以访问当前页面和子页面。

Notion 的按钮文字可能随版本略有差异，目标始终是把内部连接授权给这个父页面
及其子页面。

跳过本步骤会导致数据库创建失败。

## 6. 复制完整父页面链接

官方说明：

- [共享与复制页面链接](https://www.notion.com/help/share-your-work)

操作步骤：

1. 打开父页面。
2. 点击右上角“共享”。
3. 点击“复制链接”。
4. 保存完整链接，等待本地安全设置界面使用。

不需要手动查找页面编号，不需要截取链接中的字符串，也不需要把页面公开到
互联网。本地程序可以直接接收完整链接并自动提取编号。

用户不需要手动提取页面编号。

## 7. 本地安全设置

正式流程：

1. Codex 自动获取或定位完整项目。
2. Codex 自动准备项目内的本地运行环境。
3. Codex 自动启动安全首次设置工具。
4. 用户在本地安全输入界面粘贴 Notion 访问密钥。
5. 用户在同一流程中粘贴 Notion 父页面完整链接。
6. Codex 和本地程序自动创建和验证四个数据库。

访问密钥输入时不可见，不进入聊天、命令历史或日志。用户不需要手动编辑
`.env`（本地私密配置文件）。

如果 Codex 当前环境不能提供安全交互式输入：

1. Codex 尝试打开 `start_setup.command`（开始设置）。
2. 如果仍无法自动打开，Codex 在访达中打开项目文件夹。
3. 用户只需双击 `start_setup.command`。
4. 只有双击方式也失败时，Codex 才提供终端故障排查命令。

## 8. 设置完成

成功后，Codex 应主动显示：

```text
第一次设置已经完成。

以下数据库已经创建并通过验证：

- 播客资料库
- 表达资料库
- 每周复盘资料库
- 词汇资料库

现在请发送一个苹果播客单集链接、播客订阅源链接或本地音频文件。
```

用户随后可以直接发送：

```text
请使用英语音频学习助手处理这个播客：

<粘贴播客链接>
```

## 9. 播客处理

用户只需要提供苹果播客单集链接、播客订阅源链接或本地音频文件。

Codex 自动完成：

1. 检查输入是否受支持。
2. 获取或读取音频。
3. 生成文字稿。
4. 创建分析请求。
5. 读取分析请求。
6. 生成符合格式要求的分析结果。
7. 使用本地 Python 验证结果。
8. 写入 Notion。
9. 返回最终 Notion 页面链接。

用户不需要复制完整后台处理步骤，也不需要手动运行主要流程命令。

## 11. 故障排查

只有自动流程无法继续时才使用本节。

### 恢复设置时父页面不一致

第一次设置中断后，请继续使用首次创建数据库时选择的同一个 Notion 父页面。
即使页面链接外观不同，只要页面编号相同，系统也会正常继续。

如果误选另一个父页面，系统会在写入配置或操作数据库之前安全停止，不会覆盖
原来的父页面，也不会把同一套数据库拆到两个父页面。此时请重新提供原父页面
链接，或让 Codex 检查本地测试配置。

### 技能没有刷新

- 失败步骤：安装后的技能发现。
- 原因：当前对话尚未刷新技能列表。
- 权限：通常不涉及权限。
- 用户操作：先新建一个 Codex 对话并发送首次设置备用指令。
- 完成后回复：如果新对话仍未识别，再重启 Codex 并回复“已重启”。

### 数据库创建失败

- 失败步骤：Notion 工作区初始化。
- 原因：父页面未授权、密钥无效或网络暂时不可用。
- 权限：通常涉及父页面连接权限。
- 用户操作：确认内部连接已添加到父页面，不要发送访问密钥。
- 完成后回复：“页面连接已确认，请重试设置。”

### 自动设置窗口没有打开

- 失败步骤：本地安全设置启动。
- 原因：当前 Codex 环境无法启动交互式窗口。
- 权限：可能需要批准打开本地文件。
- 用户操作：双击项目中的 `start_setup.command`；Codex 应先自动在访达中打开
  正确项目目录。
- 完成后回复：“设置窗口已完成”或提供不含密钥的错误信息。

### 音频处理失败

- 失败步骤：输入解析、音频获取或文字稿生成。
- 原因：链接类型不受支持、网络失败或音频不可读。
- 权限：本地文件可能需要读取权限。
- 用户操作：根据 Codex 指出的具体阶段重新提供链接或批准文件访问。
- 完成后回复：“可以重试”。
